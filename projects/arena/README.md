# 最后三分钟 / Last Three Minutes

一个使用 Vulcal Engine 现有 Lua、精灵和场景接口实现的单屏生存小游戏。没有外部美术资源、字体或额外依赖。

## 运行

先按仓库根 README 构建引擎，启动 `./build/bin/editor`，通过编辑器打开本目录的 `arena.vproj`，然后点击 **Play**。

建议将游戏视口调整为 **4:3 或更宽**，避免侧边 HUD 在过窄视口中被裁切。游戏在等待界面停留，按 **Enter** 开始。键盘输入需要编辑器窗口处于焦点；游戏期间避免在其他编辑器面板的文本框中输入。

| 按键 | 操作 |
| --- | --- |
| WASD | 移动，斜向移动不加速 |
| 方向键 | 按住持续四向射击，不自动瞄准 |
| 空格 | 向当前移动方向冲刺；静止时沿最后移动方向 |
| Enter | 开始游戏，或在胜负结算后重开 |

同时按住多个射击方向时，最近按下且仍按住的方向优先；释放后退回之前仍按住的方向。引擎不提供同一帧内的按键事件时间，因此同帧按下的方向按 Up、Down、Left、Right 的顺序处理，后者优先。

## 规则

- 在封闭场地内存活 **180 秒**即获胜。生命为 **3 点**，接触敌人损失一点，之后无敌一秒。
- 青绿色为玩家；红色普通敌人较慢、需要两发子弹；橙色快速敌人一发即可击杀，从第 30 秒起混合出现。
- 每 30 秒提高刷新频率，最多同时存在 90 个敌人；新敌人从边缘生成，避开玩家附近。
- 冲刺持续 0.15 秒、发动后冷却一秒；冲刺时无敌，但不能穿越场地边界。
- 子弹不穿透敌人。最后一步同时受到致命伤害并达到 180 秒时，判定失败。
- 左侧显示生命与冲刺冷却，右侧显示剩余秒数、时间条与击杀数。
- 结算后战斗冻结，短暂粒子和震屏自然结束；Enter 完整重置一局。

## 实现与调整

逻辑集中在 `assets/scripts/arena.lua`，顶部 `config` 表控制时长、移动、冲刺、射击和实体预算。场地、HUD 和提示字形均由无纹理精灵组成，不修改引擎 API。

采用 120 Hz 固定步长，每帧最多补 12 步。严重卡顿或窗口长时间停顿时会丢弃多余积压时间，因此三分钟是**模拟时间**，不是严格的墙钟时间。单帧内最新输入作用于该帧补步。未提供暂停、音频、存档、联网或独立发布器。

## 测试

在仓库根目录运行：

```sh
cmake --build build --target editor_state_test --parallel
ctest --test-dir build -R 'Arena' -LE graphics --output-on-failure
```

测试使用项目已有的 Lua 库，不依赖系统安装的 Lua 命令行工具。包括真实场景与 Lua 绑定的启动/停止集成测试，以及输入、碰撞、计时、无敌、实体预算和反复重开的测试桩验证。

可选图形回归（需要可用的 OpenGL 4.6 显示环境）：

```sh
cmake -S . -B build -DBUILD_GRAPHICS_TESTS=ON
cmake --build build --target arena_graphics_test --parallel
ctest --test-dir build -R 'ArenaGraphics' --output-on-failure
```

图形测试使用真实 SDL 键盘事件，验证开始、移动、冲刺、射击、失败、重开和 HUD 像素读回。运行前可设置 `VULCAL_ARENA_CAPTURE_DIR` 为截图目录，保存等待、战斗、失败及重开画面的 PPM 文件。
